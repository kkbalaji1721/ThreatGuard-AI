# ThreatGuard AI — Multi-Platform Threat Intelligence Assistant

ThreatGuard AI is an educational, defensive cybersecurity assistant that answers threat-intelligence questions for Windows, Linux, macOS, Android and iOS.

It uses FastAPI, Streamlit, MongoDB and Ollama to provide a chat interface with knowledge-base retrieval and locally hosted AI models.

## Features

- **Streamlit frontend:** Chat interface with platform and threat-status filters.
- **FastAPI backend:** REST API for chat, threats, ingestion, sessions, health and metrics.
- **MongoDB:** Stores threat records, knowledge chunks, embeddings and chat sessions.
- **Ollama:** Runs the local LLM and embedding models.
- **RAG retrieval:** Retrieves relevant stored knowledge to support answers.
- **Docker Compose:** Runs the application and its supporting services.
- **Prometheus metrics:** Provides application monitoring information.
- **Read-only inventory:** Reports information about the application container.

## Installation and Setup

### 1. Clone the repository

```powershell
git clone https://github.com/kkbalaji1721/ThreatGuard-AI.git
cd ThreatGuard-AI
```

### 2. Configure environment variables

Copy the environment template:

```powershell
Copy-Item .env.example .env
```

Open `.env` and configure the required settings. Keep your passwords and API keys private. Do not upload `.env` to GitHub.

### 3. Start the application

Start the application with the local Ollama service:

```powershell
docker compose --profile local-llm up --build -d
```

### 4. Download the AI models

```powershell
docker exec -it threatguard-ollama ollama pull llama3.2:3b
docker exec -it threatguard-ollama ollama pull nomic-embed-text
```

### 5. Check running services

```powershell
docker compose ps
```

View application logs:

```powershell
docker compose logs app
```

## API Endpoints

- `/chat` — Ask cybersecurity questions.
- `/threats` — Retrieve threat records.
- `/ingest` — Add knowledge documents.
- `/sessions/{id}` — Retrieve chat history.
- `/stats` — Application statistics.
- `/health` — Check application and database health.
- `/metrics` — Prometheus metrics.
- `/scan/local` — Read-only application-container inventory.

## How the AI Works

1. The user submits a cybersecurity question through Streamlit.
2. The frontend sends the question to FastAPI.
3. The backend checks the threat knowledge base.
4. Relevant stored knowledge can be retrieved using embeddings and cosine similarity.
5. Ollama generates an answer for general questions.
6. Chat history is stored in MongoDB.

Exact known Threat IDs can retrieve their corresponding stored records directly.

## Database

MongoDB stores information in the following collections:

- `threats` — Threat intelligence records.
- `knowledge` — Knowledge chunks and embeddings.
- `sessions` — Persistent conversation history.

The Docker Compose configuration uses a persistent MongoDB volume.

## Threat Status Definitions

- **Anticipated:** A possible emerging risk that requires monitoring.
- **Active:** A threat currently reported or confirmed by its source.
- **Evolving:** New information or changes are affecting the threat.
- **Resolved:** A fix or mitigation has been reported; the target system still needs verification.

The included threat records are educational sample data, not a real-time threat feed.

## Important Limitations

- This project is an educational threat-intelligence assistant, not a replacement for antivirus or endpoint protection.
- Answers generated by an LLM may occasionally be inaccurate and should be checked against trusted security advisories.
- The `/scan/local` endpoint reports information about the application container; it does not scan the Windows host for malware.
- The project does not automatically patch systems or perform remediation.
- Local retrieval uses cosine similarity over stored embeddings; the demonstrated setup does not use MongoDB Atlas Vector Search.

## Stop the Application

To stop the Docker services:

```powershell
docker compose down
```

This preserves the named database and model volumes.
